# NewsPortalApp

Frontend Angular pentru News Portal — built cu Angular CLI 21.

## Pornire

```bash
npm install
ng serve
```

Aplicatia ruleaza pe `http://localhost:4200/`. Backend-ul (proiectul .NET din `../backend/`) trebuie pornit separat pe `https://localhost:7001` — vezi `environments/environment.development.ts` pentru `apiUrl`.

## Build

```bash
ng build
```

Output in `dist/`.

## Tests

```bash
ng test
```
